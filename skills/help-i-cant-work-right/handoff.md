# External repair prompt

Fill from observed evidence, redact credentials, and return one portable prompt when the current host cannot repair itself:

Repair and verify PROJECT [absolute path]. Read its AGENTS.md, README and relevant host/diagnosis/agent-writing skills. Preserve existing Quest [ID], steps [IDs], original intent [scope], decisions, explicit provider/model/reasoning, and authorization [allowed/prohibited actions].

Observed failure: [operation, time, result, actual role, tools, workspace, launch ID/state]. Source [commit/path] versus selected [generation] versus actually loaded [receipt or unknown]. Prior attempts [preconditions and results]. Preserve dirty work [owner/path/commit], live/unknown workers [identities and last observations], existing implementation [paths]. Reuse typed records; never directly repair a shared ledger or invent completion.

Use an authorized supported tool-capable route. Diagnose role/tool filtering separately from model binding. Verify one isolated worker on the exact requested route reports identity, writes/reads a task-owned fixture, executes a harmless check and records the result. Verify terminal reconciliation, fresh quota and one next eligible launch; duplicate events and competing givers must not duplicate work. Preserve cancellation, account policy and unknown-launch safety. Record commands, actual results, commits, integration/load status and rollback. Reconcile workers and resume [next safe operation] on the existing Quest with [unfinished work] intact. Return minimal fresh-launch/restart instructions if required.
