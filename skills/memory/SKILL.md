# Memory

Write a line only if it would otherwise be lost. If code, config, git history or an AGENTS.md
carries it, every session pays to read a duplicate.

Earns a line: a decision the user made, or a lesson that cost real time, with its evidence.

One line each. Correct stale in place, delete wrong, never narrate work.
