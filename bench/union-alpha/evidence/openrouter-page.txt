Union Alpha is a multimodal model built for research, coding, and agentic workflows, while delivering frontier-level performance across a broad range of general-purpose tasks. Union Alpha is a stealth model. It is developed and operated by a third-party provider who has chosen to remain anonymous during this preview. OpenRouter routes requests to it and is not its developer, owner, or provider. Is Union Alpha free? Yes. The pricing shown on this page for Union Alpha is zero, so you are not charged for prompt or completion tokens. What is the context length of Union Alpha? Union Alpha has a 262,144 token context window. It supports up to 131,072 completion tokens. Does Union Alpha support tool calling and structured outputs? Yes. Union Alpha accepts tools and tool_choice for function calling. It supports response_format for JSON output, without JSON-schema enforcement. What inputs and outputs does Union Alpha support? Union Alpha accepts text and images as input and returns text. When was Union Alpha released? Union Alpha was released on September 16, 2026.
