# Glossary — spoken forms and what they mean

Dictation replaces product names with similar-sounding English words. Resolve these silently; never
correct the user's spelling back at them, and never ask which one was meant when the table settles it.

| heard / typed | means |
|---|---|
| Ermes | Hermes |
| OpenCOD two, open code two, Open Code Two | OpenCode 2 |
| cloud flare | Cloudflare |
| for sell (next to "agents MD") | Vercel |
| ses seed | the `ses_` session id |
| procedular | procedural |
| owrding | wording |
| immedietly broguth | immediately brought |
| inturpupt | interrupt |
| aces (to my vps) | access |
| slash quest / slash usage / slash restart | `/quest`, `/usage`, `/restart` |
| step evidence slash proof | step evidence / proof |
| everytime, alot, alittle, atleast, eachother | every time, a lot, a little, at least, each other |
| rather then, more then, better then | rather than, more than, better than (comparisons) |
| your not, your doing, its not | you're not, you're doing, it's not |

This table is the public subset; project-specific names (domains, product codenames) belong in the
glossary kept alongside the project, not here.

The correct form is usually already in the same session — the user self-corrects a turn or two later
(`Hermes` 32 times against `Ermes` 2; `OpenCode 2` 20 against `OpenCOD two` 1). Carry the correction
forward instead of re-deriving it.

A run-on turn with no sentence breaks is several requests, not one. Split it, list the parts at the top
of the reply, and do all of them.
