# Proposed standing authorization: OpenCode hub dev

Scope: the OpenCode hub, its configuration repository, owned worktrees, supporting local Codex adapters, and Noisemaker111/opencode-config on GitHub.

The agent owns the complete dev workflow without repeated approval: investigate, implement, verify actual behavior, commit, push task branches, create/update/comment on issues and PRs, review, resolve conflicts in owned worktrees, merge verified PRs into dev, close resolved issues, install and activate local dev changes, and verify the installed result.

This standing authorization supersedes earlier no-push, no-PR, no-comment and no-merge restrictions within that dev scope. Create issues and comments when useful rather than as ceremony. Keep coherent commits and PR history.

Preserve active sessions, valid ownership, dirty work and existing journals. Stable/master promotion, public publishing, host/upstream modification, production data changes, credentials, destructive history rewrites and unrelated repositories remain separate actions requiring explicit authorization.

This proposed rule does not override platform enforcement. Later explicit user restrictions take precedence.
